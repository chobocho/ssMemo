# ssMemo2 수동 점검표

화면 동작은 자동 테스트 수단이 없어서, 마일스톤마다 이 표로 직접 확인합니다.

## 실행 방법

1. `./build.sh` 실행 (Windows는 `build.bat`)
2. `cd release && python -m http.server 8001`
3. 브라우저에서 `http://localhost:8001` 접속
   - `127.0.0.1`로 접속하면 다른 출처로 취급되어 저장 데이터가 따로 관리됩니다.
4. 화면의 `build` 값이 `build.sh`가 출력한 build 값과 같은지 먼저 확인

## 결과 알리는 방법

- 실패한 항목 번호(예: `M0-03`)와 화면의 **📋 Copy** 버튼으로 복사한 진단 정보를 함께 알려 주세요.
- 해당 없는 칸은 `-`로 둡니다.

## M2 — 저장과 복원

저장 상태는 화면 오른쪽 위에 표시됩니다. 입력을 멈추고 약 1.5초 뒤, 계속 입력 중이면 늦어도 10초마다 저장합니다.

| 번호 | 할 일 | 기대 결과 | PC | 접힘 | 펼침 |
| --- | --- | --- | --- | --- | --- |
| M2-01 | 편집기에 입력하고 2초쯤 기다리기 | 오른쪽 위 표시가 `저장 전` → `저장 중…` → `저장됨`으로 바뀐다 | ☐ | ☐ | ☐ |
| M2-02 | `저장됨`이 보인 뒤 새로고침 | 입력한 내용이 그대로 나온다 | ☐ | ☐ | ☐ |
| M2-03 | 브라우저를 완전히 닫았다가 다시 열어 접속 | 입력한 내용이 그대로 나온다 | ☐ | ☐ | ☐ |
| M2-04 | 입력하자마자(`저장 전` 상태) 탭 닫기 | "사이트에서 나가시겠습니까?" 같은 확인 창이 뜬다 | ☐ | - | - |
| M2-05 | 입력하자마자 홈 화면으로 나갔다가 돌아와 새로고침 | 입력한 내용이 그대로 나온다 | - | ☐ | ☐ |
| M2-06 | 주소 끝에 `?safe`를 붙여 접속 | `⚠️ 임시 모드` 표시와 안내 줄이 나오고, 저장해 둔 메모는 보이지 않는다 | ☐ | ☐ | ☐ |
| M2-07 | `?safe` 상태에서 입력 후, `?safe`를 빼고 다시 접속 | 원래 메모가 그대로 나온다 (`?safe`에서 입력한 내용은 없다) | ☐ | ☐ | ☐ |
| M2-08 | 안내 줄의 ✕ 누르기 | 안내 줄이 사라진다 | ☐ | ☐ | ☐ |
| M2-09 | 같은 주소를 탭 두 개로 열고, 첫 탭에서 입력해 `저장됨`을 확인한 뒤 둘째 탭에서 입력 | 둘째 탭에 "다른 창에서 이 메모가 바뀌어 … 따로 저장했습니다" 안내가 나온다 | ☐ | - | - |
| M2-10 | Diagnostics(진단 정보)를 펼쳐 `storage` 확인 | 평소에는 `persistent`, `?safe`에서는 `temporary (safe-mode)` | ☐ | ☐ | ☐ |

## M3 — 탭과 메모 관리

화면 위쪽 버튼: 📋 메모 목록, ↩️ 자동 줄바꿈, A− / A+ 글자 크기, 🌐 언어. 그 아래 탭 줄의 ➕는 새 메모, 각 탭의 ✕는 닫기입니다.

| 번호 | 할 일 | 기대 결과 | PC | 접힘 | 펼침 |
| --- | --- | --- | --- | --- | --- |
| M3-01 | ➕로 메모를 두세 개 만들고 각각 다른 내용 입력 | 탭이 늘어나고, 입력 중인 탭에 ● 표시가 떴다가 저장되면 사라진다 | ☐ | ☐ | ☐ |
| M3-02 | 탭을 번갈아 누르기 | 탭마다 자기 내용·커서 위치·스크롤 위치가 유지된다 | ☐ | ☐ | ☐ |
| M3-03 | 한 탭에서 입력 후 다른 탭으로 갔다가 돌아와 실행 취소 (PC는 Ctrl+Z) | 그 탭에서 한 입력만 취소된다 | ☐ | - | - |
| M3-04 | 탭을 여러 개 연 채로 새로고침 | 같은 탭들이 같은 순서로 열리고, 보고 있던 탭과 커서 위치가 복원된다 | ☐ | ☐ | ☐ |
| M3-05 | 탭이 화면 폭보다 많아지도록 열기 | 탭 줄만 좌우로 스크롤되고 페이지 전체는 밀리지 않는다 | ☐ | ☐ | ☐ |
| M3-06 | 📋에서 메모 선택 | 목록이 닫히고 그 메모가 탭으로 열린다. 이미 열린 메모면 그 탭으로 이동한다 | ☐ | ☐ | ☐ |
| M3-07 | 📋에서 ✏️로 이름 변경 (빈 제목도 시도) | 빈 제목은 거절 사유가 표시되고, 바꾼 이름이 목록과 탭에 반영된다 | ☐ | ☐ | ☐ |
| M3-08 | 📋에서 🗑️로 삭제 | 확인 창에서 취소가 먼저 선택되어 있고, 삭제하면 목록과 탭에서 사라진다 | ☐ | ☐ | ☐ |
| M3-09 | 대화상자가 열린 상태에서 ESC (모바일은 뒤로 가기) | 맨 위 창만 닫히고, 닫힌 뒤 원래 위치로 돌아간다 | ☐ | ☐ | ☐ |
| M3-10 | ↩️, A+, A−를 누른 뒤 새로고침 | 줄바꿈과 글자 크기가 바로 바뀌고 새로고침 뒤에도 유지된다 | ☐ | ☐ | ☐ |
| M3-11 | 🌐에서 English 선택 후, 다시 한국어 선택 | 페이지가 다시 열리며 문구가 바뀐다. 메모 내용은 그대로다 | ☐ | ☐ | ☐ |
| M3-12 | 편집기 아래 상태 줄 확인 | 커서를 옮기거나 입력하면 줄·칸·글자 수가 바뀐다 | ☐ | ☐ | ☐ |
| M3-13 | (PC) Alt+N, Alt+W, Alt+PageDown, Alt+O, Alt+Z | 새 메모, 탭 닫기, 다음 탭, 메모 목록, 줄바꿈 전환이 된다. 한글 입력 상태에서도 동작한다 | ☐ | - | - |
| M3-14 | 접힌 화면에서 위쪽 버튼과 탭 확인 | 버튼이 잘리지 않고(줄이 바뀌어도 됨) 손가락으로 누르기에 충분히 크다 | - | ☐ | - |

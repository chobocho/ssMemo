# ssMemo2 수동 점검표

화면 동작은 자동 테스트 수단이 없어서, 마일스톤마다 이 표로 직접 확인합니다.

## 실행 방법

1. `./build.sh` 실행 (Windows는 `build.bat`)
2. `cd release && python -m http.server 8001`
3. 브라우저에서 `http://localhost:8001` 접속
   - `127.0.0.1`로 접속하면 다른 출처로 취급되어 저장 데이터가 따로 관리됩니다.
4. ❓ 도움말(F1, 좁은 화면은 ☰ → 도움말)의 "정보"에 나오는 빌드 값이 `build.sh`가 출력한 build 값과 같은지 먼저 확인

## 결과 알리는 방법

- 실패한 항목 번호(예: `M0-03`)와 진단 정보를 함께 알려 주세요. 진단 정보는 ❓ 도움말 맨 아래 **ℹ️ 진단 정보**를 펼쳐 **📋 복사**로 복사합니다.
  - M5부터 진단 정보가 화면 맨 아래에서 도움말 안으로 옮겨졌습니다. 아래 M0~M2 절의 "화면 맨 아래" 설명은 도움말로 바꿔 읽어 주세요.
- 해당 없는 칸은 `-`로 둡니다.

## M4 — 파일과 백업

화면 위쪽 버튼: 📋 메모 목록, 📂 파일 열기, 💾 파일로 저장, ☰ 메뉴. 🔤 인코딩, 📤 백업 내보내기, 📥 백업 가져오기는 ☰ 메뉴 안에 있습니다.

준비물: UTF-8 텍스트 파일 두세 개, 메모장에서 "ANSI"(CP949)로 저장한 한글 파일 하나, 약 5MB 파일 하나.

```bash
python3 -c "print('한글 테스트 줄 0123456789 abcdefghij\n' * 110000)" > big.txt
```

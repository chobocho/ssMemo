# ssMemo2

브라우저에서 동작하는 메모장입니다. 빌드 결과는 `index.html` 파일 하나이고, 실행할 때 외부 서버·CDN·웹 폰트를 전혀 참조하지 않아 폐쇄망에서도 쓸 수 있습니다.

[ssMemoWeb](../ssMemoWeb)을 TypeScript와 CodeMirror 6로 다시 만드는 프로젝트입니다.

## 현재 상태

- 로드맵의 Phase 0~6(M6)과 Phase 7의 추가 기능 9가지를 마쳤습니다. 계획과 진행 기록은 [TODO.md](TODO.md) 10절과 [history.html](history.html)에 있습니다. 구현 전에 승인된 설계 계획은 [plan.md](plan.md)에 있습니다.
- 로직과 빌드 산출물은 자동 테스트로 검증합니다(`npm run verify`).
- **화면 모양과 터치 동작은 실제 브라우저에서 아직 확인되지 않았습니다.** 개발 환경에 브라우저가 없어 [수동 점검표](test/manual/checklist.md)로 남겨 두었습니다. 점검 결과에 따라 화면 배치가 달라질 수 있습니다.
- Phase 7에서 남겨 둔 것은 두 가지입니다: 새로고침 뒤에도 파일 연결 유지, 반쯤 접은 자세의 화면 배치. 둘 다 실제 브라우저·기기 없이는 만들 수 없어 미뤘습니다.

## 한눈에 보기

- 파일 하나(`index.html`)로 동작하고, 실행 중 네트워크 요청이 없습니다.
- 메모는 브라우저 IndexedDB에 자동 저장되고, 열어 둔 탭과 커서 위치까지 다음 접속에 복원됩니다.
- 로컬 텍스트 파일을 인코딩(UTF-8, UTF-16, CP949, 조합형)과 줄바꿈을 유지한 채 열고 저장합니다.
- 전체 메모를 JSON 하나로 백업하고 복원합니다. 한 달 동안 백업이 없으면 알려 줍니다.
- 삭제한 메모는 휴지통에 30일 동안 남아 되살릴 수 있고, 메모 목록에서 모든 메모의 본문을 한 번에 찾을 수 있습니다.
- 찾기·바꾸기, 마크다운 미리보기, 큰 정수 계산기, 절취선 나누기, 기호 단축키가 있습니다.
- 한국어와 영어, 밝은 테마와 어두운 테마를 지원하고, PC·휴대폰·폴더블(접힘/펼침) 화면 폭에 맞춰 구성이 바뀝니다.
- 콘텐츠 보안 정책(CSP)을 페이지에 담아, 브라우저가 페이지 밖의 것은 아무것도 불러오지 않고 페이지 자신의 스크립트만 실행하게 합니다.

## 사용법

- **메모와 탭**: 탭 줄의 ➕로 새 메모를 만들고, 탭을 눌러 오갑니다. 탭마다 실행 취소 이력·커서·스크롤이 따로 유지됩니다. 다시 접속하면 열어 둔 탭이 그대로 복원됩니다.
- **자동 저장**: 입력을 멈추고 약 1.5초 뒤, 계속 입력 중이면 늦어도 10초마다 저장합니다. 탭을 떠날 때와 화면을 가리거나 닫을 때도 저장합니다. 저장 전인 탭에는 ● 표시가 붙습니다.
- **메모 목록(📋)**: 저장된 메모를 열고, 이름을 바꾸고, 삭제합니다.
  - 위쪽 입력란에 글자를 넣으면 본문이나 제목에 그 글자가 있는 메모만 일치한 줄과 함께 보입니다(대소문자 구분 없음). 골라서 열면 편집기의 찾기가 같은 검색어로 이어집니다.
  - ↕️ 정렬 버튼으로 최근 수정 순, 최근 만든 순, 제목 순 가운데 고릅니다. 고른 순서는 저장되고 검색 결과에도 적용됩니다.
- **메모 고정(☰ → 📌)**: 보고 있는 메모를 고정하면 어떤 정렬에서도 메모 목록 맨 위에 📌 표시와 함께 보입니다. 같은 명령으로 해제합니다. 메뉴에서 지금 메모가 고정되어 있는지 볼 수 있습니다.
- **휴지통(🗑️)**: 삭제한 메모는 휴지통으로 옮겨져 30일 동안 남습니다. 메모 목록 아래의 버튼이나 ☰ 메뉴로 열어 되살리거나(↩️) 완전히 삭제하고, 한꺼번에 비울 수 있습니다.
  - 되살린 메모는 바로 탭으로 열립니다. 같은 메모가 그사이 백업에서 돌아와 있어도 덮어쓰지 않고 따로 되살립니다.
- **메뉴(☰)**: 모든 명령이 이름·단축키와 함께 나옵니다. 좁은 화면에서는 툴바에 📋 📂 💾 ☰만 보이고 나머지는 메뉴에 있습니다.
- **파일 열기(📂)**: 여러 파일을 한 번에 고르거나 화면에 끌어다 놓으면 파일마다 탭이 열립니다. 10MB까지 열 수 있고, 텍스트가 아닌 파일은 거절합니다.
  - 인코딩(UTF-8, UTF-16, CP949, 조합형)과 줄바꿈(LF, CRLF, CR)을 자동으로 알아내 상태 줄 끝에 표시합니다.
  - 글자가 깨져 보이면 편집하기 전에 ☰ → 🔤 인코딩에서 다른 인코딩으로 다시 읽을 수 있습니다.
  - 보기만 한 파일은 흔적을 남기지 않습니다. 고친 파일은 자동 저장되어 메모 목록에 파일 이름으로 남고, 다시 접속하면 복원됩니다.
- **파일로 저장(💾)**: 보고 있는 탭을 파일로 저장합니다. 인코딩·BOM·줄바꿈은 원본대로 유지합니다.
  - PC의 Chrome·Edge처럼 파일 접근을 지원하는 브라우저에서는 위치를 한 번 고르면 그다음부터 그 파일에 바로 저장합니다. 그 밖의 브라우저에서는 다운로드됩니다.
  - CP949·조합형 파일은 UTF-8로만 저장할 수 있어, 저장하기 전에 먼저 묻습니다.
- **백업(☰ → 📤 / 📥)**: 모든 메모와 설정을 JSON 파일 하나로 내보내고 다시 가져옵니다.
  - 가져올 때 "추가"는 저장된 메모를 덮어쓰지 않습니다. 같은 메모가 내용만 다르면 "(가져옴)" 사본으로 들어옵니다.
  - "교체"는 저장된 메모를 모두 지우고 백업만 남기며, 한 번 더 확인합니다.
  - 백업 파일은 들여쓴 JSON이라 직접 읽고 고칠 수 있습니다. `app`과 `documents`의 `content`만 있으면 가져올 수 있습니다.
  - 메모가 있는데 30일 동안 백업을 내보내지 않으면 시작할 때 한 번 알려 줍니다. 알린 뒤에는 다시 30일 동안 조용합니다.
- **ssMemoWeb 메모 자동 가져오기**: ssMemoWeb을 지금과 같은 주소에서 썼다면, ssMemo2를 처음 열 때 브라우저에 남아 있는 그 메모들을 묻지 않고 새 메모로 가져오고 몇 개를 가져왔는지 알려 줍니다. ssMemoWeb의 데이터는 바꾸지 않습니다. 한 번만 하므로, 가져온 메모를 여기서 지우거나 고쳐도 다음에 열 때 되살아나지 않습니다. 임시 모드(`?safe`)에서는 하지 않습니다.
  - 그 뒤에 ssMemoWeb에서 새로 쓴 메모는 ☰ → 🗃️ ssMemoWeb 메모 가져오기로 직접 가져옵니다. 이때는 개수를 먼저 묻고, 이미 있는 메모는 다시 가져오지 않습니다.
- **공유(☰ → 📨)**: 보고 있는 메모의 제목과 본문을 시스템 공유 창으로 넘깁니다(주로 휴대폰). 10만 자가 넘으면 텍스트 파일로 공유하고, 공유를 지원하지 않는 브라우저에서는 안내만 나옵니다.
- **찾기(🔍)**: 편집기 위쪽에 찾기·바꾸기 줄이 열립니다. 대소문자 구분, 정규식, 단어 단위 검색을 지원하고, 검색어는 탭을 바꿔도 유지됩니다.
- **넣기**: 구분선(➖)과 기호(→ ✅ □ ※ ❎ 🟩)를 커서 위치에 넣습니다. 실행 취소가 됩니다.
- **절취선(➗)**: 긴 메모를 2000자마다 절취선으로 나누고, 다시 누르면 합칩니다. 나눈 뒤에는 검색어가 "절취선"으로 맞춰져 "다음 찾기"로 조각 사이를 이동할 수 있습니다.
- **마크다운 미리보기(📖)**: 넓은 화면에서는 편집기 옆에, 좁은 화면에서는 편집기 대신 보입니다. 입력을 멈추면 잠시 뒤 따라 바뀝니다. 이미지는 지원하지 않습니다(외부 요청이 되므로).
- **계산(🧮)**: 선택한 내용이나 커서가 있는 줄을 계산합니다. `+ - * / //`, 괄호, 변수, `sin` `cos` `tan` `factorial`, `#` 주석을 쓸 수 있고 정수는 자릿수 제한 없이 정확합니다.
  - 결과 창에서 결과를 메모에 `#` 주석 줄로 넣거나, 변수를 저장해 다음 계산에서 쓸 수 있습니다. 저장한 변수는 다시 접속해도 남고 백업에도 들어갑니다.
- **웹 주소 열기(🔗)**: 선택한 주소나 커서가 놓인 주소를 새 탭으로 엽니다. PC에서는 주소를 선택하고 오른쪽 클릭해도 열립니다.
- **도움말(❓)**: 모든 명령과 단축키, 빌드, 오픈 소스 라이선스, 진단 정보가 있습니다.
- **보기 설정**: ↩️ 자동 줄바꿈, A− / A+ 글자 크기, 🌓 테마(자동·밝게·어둡게), 🌐 언어(자동·한국어·English). 설정은 브라우저에 저장됩니다. 테마가 자동이면 시스템 설정을 따릅니다.
- **저장 보호**: 메모를 처음 저장한 뒤, 공간이 부족해도 메모를 지우지 말아 달라고 브라우저에 요청합니다. 받아들여졌는지와 저장 공간 사용량은 진단 정보의 storage durability 줄에 나옵니다.
- **다른 창과의 충돌**: 같은 메모를 브라우저 탭 두 개에서 고치면, 늦게 저장한 쪽의 내용은 덮어쓰지 않고 "(충돌 사본)" 메모로 따로 저장합니다.
- **임시 모드**: 저장소를 쓸 수 없으면 메모가 페이지를 닫을 때까지만 유지됩니다. 주소 끝에 `?safe`를 붙이면 저장된 데이터를 건드리지 않고 임시 모드로 시작합니다. 임시 모드에서도 백업 내보내기로 내용을 꺼낼 수 있습니다.
- **진단 정보**: ❓ 도움말 맨 아래 ℹ️를 펼치면 빌드 ID와 기기 정보가 나옵니다. 문제를 알릴 때 복사해 주세요.

### 화면 폭에 따른 구성

| 화면 | 툴바 버튼 | 찾기 줄 | 미리보기 |
| --- | --- | --- | --- |
| 좁음 (480px 미만: 폴드 접힘, 휴대폰) | 📋 📂 💾 ☰ | 입력란·다음·이전 한 줄 | 편집기 대신 표시, "편집으로 돌아가기" 버튼 |
| 중간 (840px 미만: 폴드 펼침) | 위 + 🔍 📖 ❓ | 옵션·바꾸기 포함 | 편집기 대신 표시 |
| 넓음 (PC) | 전부 (↩️ A− A+ 🌐 포함) | 옵션·바꾸기 포함 | 편집기와 나란히 |

- 툴바에 없는 명령은 언제나 ☰ 메뉴에 있습니다.
- 경계는 글자 크기 기준(30em, 52.5em)이라 브라우저 글자 크기 설정을 따라 움직입니다.

### 키보드와 화면 낭독기

- 탭 줄은 Tab 키로 한 번만 멈춥니다. 그 안에서 ← →, Home, End로 탭을 옮기고 Delete로 닫습니다.
- 대화상자는 ESC로 닫히고, 닫히면 원래 있던 곳으로 포커스가 돌아갑니다.
- 경고는 화면 낭독기가 즉시 읽고, "저장했습니다" 같은 확인은 차례가 되면 읽습니다.
- 페이지 제목에 보고 있는 메모의 이름이 들어갑니다.

### 백업 파일 형식

```json
{
  "app": "ssMemo2",
  "formatVersion": 1,
  "exportedAt": "2026-11-17T03:04:05.000Z",
  "appBuild": "0.1.0+1940d956",
  "settings": { "language": "auto", "lineWrapping": true, "editorFontSizeRem": 0.875 },
  "calcMemory": { "rate": { "big": "1250" }, "ratio": { "num": 0.5 } },
  "documents": [
    {
      "id": "0b9f5c1e-7d1e-4b6a-9a51-2f0c1d6f7a10",
      "title": "장보기",
      "createdAt": "2026-11-01T09:00:00.000Z",
      "updatedAt": "2026-11-16T12:30:00.000Z",
      "content": "우유\n달걀"
    },
    {
      "id": "5a2c8f0e-3b47-4c1d-8e9a-6d1b2c3f4a5b",
      "title": "notes.txt",
      "createdAt": "2026-11-10T08:00:00.000Z",
      "updatedAt": "2026-11-10T08:05:00.000Z",
      "content": "파일에서 연 문서",
      "source": { "fileName": "notes.txt", "encoding": "CP949", "eol": "crlf", "hasBom": false }
    }
  ]
}
```

- 꼭 있어야 하는 것은 `"app": "ssMemo2"`와 `documents` 배열, 그리고 각 문서의 `content`뿐입니다. 나머지는 없으면 가져올 때 채웁니다(id, 제목, 시각).
- 모르는 항목은 무시하므로 항목을 덧붙여도 읽힙니다. 본문이 없는 문서는 건너뛰고 몇 개였는지 알려 줍니다.
- `calcMemory`의 `big`은 자릿수 제한 없는 정수(문자열), `num`은 소수입니다.
- `source`는 파일에서 연 문서에만 있습니다.

### 알아 둘 점

- 조합형 파일의 한자와 기호는 읽지 못해 대체 문자(U+FFFD)로 표시됩니다.
- 웹 주소 바로 뒤에 한글이 붙어 있으면 함께 주소로 읽힙니다. 그럴 때는 주소만 선택해서 여세요.
- 미리보기는 50만 자가 넘는 메모를 렌더링하지 않고, 계산은 한 번에 10만 자까지만 받습니다.
- 줄바꿈이 섞인 파일은 저장하면 가장 많이 쓰인 줄바꿈으로 통일됩니다.
- 파일과의 연결(제자리 저장)은 페이지를 새로고침하면 사라져, 다음 저장 때 위치를 다시 묻습니다.
- 백업은 모든 메모를 한꺼번에 메모리에 올립니다. 큰 메모가 아주 많으면 휴대폰에서는 무리가 될 수 있습니다. 모든 메모에서 찾기도 마찬가지입니다.
- 휴지통에는 최근에 삭제한 30개, 합쳐서 500만 자까지만 남습니다(가장 최근 것은 크기와 상관없이 남습니다). 휴지통의 메모는 백업에 들어가지 않습니다.
- 저장 보호 요청을 브라우저가 거절할 수 있습니다(진단 정보에 best-effort로 표시). 그때는 백업이 유일한 안전장치입니다.
- ssMemoWeb 메모 가져오기는 계산기 변수와 빈 메모를 가져오지 않습니다.
- 메모 고정은 백업에 들어가지 않습니다. 고정한 메모를 삭제하면 고정도 풀려, 휴지통에서 되살리면 보통 메모로 돌아옵니다. 아직 아무것도 쓰지 않은 새 메모는 고정할 수 없습니다.

## 지원 환경

| 환경 | 메모·탭·백업 | 파일 저장 방식 | 비고 |
| --- | --- | --- | --- |
| PC Chrome, Edge | ✅ | 고른 파일에 제자리 저장 | 주 대상 |
| Android Chrome, 삼성 인터넷 (폴드 포함) | ✅ | 제자리 저장 또는 다운로드 (브라우저 버전에 따름) | 주 대상 |
| Firefox, Safari (iOS 포함) | ✅ | 다운로드 | 되는 범위에서 지원 |

- 제자리 저장은 파일 접근 API가 있고 `http://localhost` 또는 https로 접속했을 때만 됩니다.
- IndexedDB를 쓸 수 없는 환경(일부 사생활 보호 모드 등)에서는 임시 모드로 동작하고, 화면에 배지로 표시합니다.

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 메모가 사라졌다 | `localhost`와 `127.0.0.1`, 포트가 다르면 저장 공간이 서로 다릅니다. 같은 주소로 접속했는지 확인하세요. |
| "⚠️ 임시 모드" 배지가 보인다 | 브라우저 저장소를 쓸 수 없는 상태입니다. 사생활 보호 창이 아닌지 확인하고, 중요한 내용은 ☰ → 📤 백업 내보내기로 꺼내 두세요. |
| 앱이 열리지 않거나 저장된 메모 때문에 멈춘다 | 주소 끝에 `?safe`를 붙이면 저장된 데이터를 읽지 않고 시작합니다. |
| "ssMemo2를 시작하지 못했습니다"만 보인다 | 새로고침해 보고, 안 되면 주소 끝에 `?safe`를 붙이거나 다른 브라우저로 여세요. 개발자 도구 콘솔에 원인이 남습니다. 파일을 고쳐 저장했다면 스크립트 해시가 달라져 브라우저가 실행을 막은 것일 수 있으니 원본 `index.html`을 다시 받으세요. |
| ssMemoWeb 메모를 찾지 못한다 | 브라우저는 주소(프로토콜·호스트·포트)마다 저장 공간을 따로 둡니다. ssMemoWeb을 쓰던 바로 그 주소로 ssMemo2를 열어야 합니다. |
| 한글이 깨져 보인다 | 편집하기 전에 ☰ → 🔤 인코딩에서 CP949나 조합형으로 다시 읽으세요. |
| 저장할 때마다 위치를 묻는다 | 새로고침하면 파일과의 연결이 끊깁니다. 파일 접근 API가 없는 브라우저에서는 매번 다운로드됩니다. |
| 단축키가 브라우저 기능으로 동작한다 | 일부 브라우저·확장 프로그램이 키를 먼저 가져갑니다. 같은 명령이 ☰ 메뉴에 있습니다. |
| "저장 공간이 가득 찼습니다" | 필요 없는 메모를 지우거나 백업한 뒤 정리하세요. 브라우저가 사이트마다 주는 공간에는 한도가 있습니다. |

문제를 알릴 때는 ❓ 도움말 맨 아래의 진단 정보를 복사해 함께 보내 주세요.

## 필요한 것

- 빌드: Node.js 24 이상과 npm. 처음 한 번은 의존성 설치를 위해 인터넷이 필요합니다.
- 실행: 브라우저만 있으면 됩니다.

## 빌드와 실행

```bash
./build.sh            # Windows는 build.bat
cd release
python -m http.server 8001
```

- 브라우저에서 `http://localhost:8001`로 접속합니다.
  - `127.0.0.1`은 다른 출처로 취급되어 저장 데이터가 따로 관리됩니다.
  - 다른 기기에서 IP 주소로 접속하면 보안 컨텍스트가 아니어서 일부 기능(파일 제자리 저장 등)을 쓸 수 없습니다.
- `release/` 폴더에는 `index.html`만 복사됩니다.
- `./build.sh <폴더>`처럼 대상 폴더를 지정할 수 있습니다. 대상 폴더의 다른 파일은 지우지 않습니다.
- `build.bat`은 바이트와 구조만 검증했고, Windows에서 실제로 실행해 보지는 못했습니다.

## 개발

| 명령 | 하는 일 |
| --- | --- |
| `npm run check` | 타입 검사 (tsc) |
| `npm test` | 단위 테스트 |
| `npm run build` | `dist/index.html` 생성 |
| `npm run test:build` | 빌드 산출물과 빌드 스크립트 검증 |
| `npm run verify` | 위 네 가지를 순서대로 실행 |
| `npm run gen:bat` | `scripts/build.bat.template`에서 `build.bat`(cp949 + CRLF) 재생성 |

- 테스트는 Node 내장 러너로 `.ts` 파일을 그대로 실행합니다. 그래서 소스는 `enum`·`namespace`를 쓰지 않고, 상대 import에 `.ts` 확장자를 붙입니다.
- 화면 코드는 jsdom으로 테스트하고, `test/build/appSmoke.test.ts`가 빌드된 페이지를 jsdom에서 실제로 부팅해 봅니다. jsdom에는 레이아웃이 없으므로 모양과 터치 동작은 수동 점검표로 확인합니다.
- 타입 검사는 TypeScript 6.x를 씁니다. 7.x는 Android용 실행 파일이 없습니다.
- 빌드는 외부 참조(외부 `src`/`href`, `@import`, `fetch` 등)가 하나라도 있으면 실패합니다.
- 명령을 추가할 때는 `src/app/commandTable.ts`에 정의를 넣습니다. 메뉴·도움말·단축키 처리가 이 표에서 만들어지고, 편집기 키와 겹치면 테스트가 실패합니다.
- npm 패키지를 추가해 번들에 들어가면 `src/app/licenses.ts`의 고지 목록도 고쳐야 빌드 테스트가 통과합니다.
- `build.bat`은 직접 고치지 말고 템플릿을 고친 뒤 `npm run gen:bat`을 실행하세요.

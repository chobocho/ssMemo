[2026-11-23 23:07] UX 보완과 F1 도움말 개편 (ssMemoWeb 대비)

  • 기획: ssMemo2와 ssMemoWeb을 브라우저(Chrome)에 나란히 띄워 비교했다. 찾은 문제 — ① 도움말이 맨 아래로 스크롤된 채 열림(첫 포커스가 맨 아래 "오픈 소스 라이선스"), ② 대화상자에 닫기 버튼이 없어 터치 화면에서 닫기 어려움, ③ 도움말·메뉴가 넓은 창에서도 좁은 한 단이라 스크롤이 김, ④ 도움말에 명령 이름만 있고 ssMemoWeb 같은 설명이 없음, ⑤ PC에서 시작 직후 편집기에 포커스가 없어 클릭해야 입력됨(ssMemoWeb은 바로 입력), ⑥ 툴바·탭을 누르면 포커스를 빼앗김, ⑦ 버튼에 마우스를 올려도 반응이 없음, ⑧ 메모 이름을 메모 목록에서만 바꿀 수 있음, ⑨ ssMemoWeb 툴바에 있던 계산·절취선 버튼이 메뉴에만 있음, ⑩ 글자 크기를 바꾼 직후 줄 번호가 줄과 어긋남.
  • 개발(도움말): 제목과 ✕가 고정된 머리글, 맨 위에서 열림, "명령이나 단축키 찾기" 입력란(여러 단어, 대소문자 무시, 이름·설명·키·알아 둘 점 모두 검색), 넓은 창에서 여러 단 배치, 명령 18개에 한 줄 설명, "알아 둘 점"을 아이콘·제목·본문 9개 항목으로 재구성(탭, 실행 취소, 백업, 좁은 화면 추가).
  • 개발(전체 UX): 모든 사용자 대화상자(메뉴·메모 목록·휴지통·계산·도움말)에 ✕ 닫기 버튼, 메뉴도 여러 단. PC(마우스 기기)에서 시작 시 편집기 포커스, 툴바·탭을 마우스로 눌러도 포커스 유지. 툴바·탭·버튼·메모 목록 호버 표시. "메모 이름 변경" 명령(F2, 탭 더블클릭)과 이름 입력란 전체 선택. 넓은 창 툴바에 🧮 계산, ➗ 절취선 추가. 글자 크기 변경 뒤 편집기를 다시 그려 줄 번호 어긋남 수정.
  • 파일: src/ui/modal.ts, helpDialog.ts, commandMenu.ts, tabBar.ts, toolbar.ts, src/app/commandTable.ts, helpContent.ts, src/editor/editorTabs.ts, src/main.ts, src/i18n/en.ts, ko.ts, src/styles/(help, modal, menu, manager, tabs, tokens), 단위 테스트 7개 파일, readme.md, test/manual/checklist.md, release/index.html (456,622바이트, 빌드 0.1.0+a880de48)
  • 검증: 타입 검사 통과, 단위 1094 passed, 0 failed(신규 17개). 빌드 테스트 92개 중 89 passed, build.sh 테스트 3개는 변경 전에도 이 Windows PC에서 실패하던 것(변경을 치워 두고 다시 돌려 확인). Chrome에서 직접 확인 — 도움말 맨 위 열림·3단·필터(ctrl s)·✕, 메뉴 3단, 탭 더블클릭 이름 변경, 툴바 클릭 뒤 계속 입력, 글자 크기 변경 뒤 줄 번호 정렬, 다크 테마.

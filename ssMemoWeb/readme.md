# ssMemo (웹 버전)

브라우저에서 동작하는 가벼운 메모 앱입니다. 외부 라이브러리 의존 없이 단일 정적 사이트로 동작하며, 사용자 데이터는 브라우저의 IndexedDB에 저장되어 이어쓰기를 지원합니다.

## 주요 기능

- 📁 파일 메뉴에 메모/파일 관련 작업 통합 (메모 관리/불러오기/저장/다운로드/메모 비우기)
- 여러 개의 메모를 IndexedDB에 저장/불러오기 (📋 메모 관리)
  - 새 메모 생성, 메모 간 전환, 이름 변경, 삭제
  - 현재 메모 제목은 메인 탭 위에 표시 (없으면 "메모장")
- **여러 메모 동시 편집** — 메모 관리의 [🗂️ 탭] 버튼으로 메모를 추가 탭에 함께 열어 편집/저장
  - 메인 메모 + 최대 7개 탭을 동시에 열 수 있으며, 각 탭은 미저장(•) 표시로 변경 상태를 알림
  - 자동 저장(3분 간격)은 메인 메모와 열려 있는 모든 메모 탭에 적용
  - 화면 전환/탭 숨김/페이지 닫기 시점에도 즉시 저장하며, 미저장 변경이 남아 있으면 닫기 전에 경고
- 텍스트 파일 불러오기/드래그 앤 드롭 — 메모 탭과 같은 슬롯(최대 7개)에 읽기 전용으로 표시
- 글자수 / 줄 번호 실시간 표시
- 강제 줄바꿈 토글, 절취선(2000자 단위 분할) 삽입
- 텍스트 검색 (다음/이전, 단축키 포함)
- 메모/파일 다운로드 (.txt)
- URL 드래그 + 우클릭으로 새 창 열기
- 마크다운 미리보기 (.md 파일 탭 📖)
- 인코딩 수동 변경 (UTF-8/CP949/Johab, 🔤)
- 코드 블럭 실행기 🧮 (5000자리 정수 산술, 변수, 함수, 영속 메모리)
- 모든 알림/확인/입력 창은 네이티브 대화상자 대신 커스텀 팝업으로 통일 (ESC 키로 닫기 가능)

## 실행 방법

외부 서버 없이 정적 파일만으로 동작합니다.

```bash
python -m http.server 8001
```

브라우저에서 `http://localhost:8001` 접속.

## 코드 블럭 실행 🧮

메모 안에 작성한 코드를 드래그로 선택한 뒤 🧮 버튼이나 `Ctrl + Enter`로 실행합니다.
선택이 없으면 커서가 위치한 줄을 실행합니다.

지원 문법:

- 사칙연산 `+ - * /`, 정수 몫 `//`, 괄호, 단항 부호
- 정수는 `BigInt`로 처리해 **5000자리 이상도 정확**
- 소수점/지수 표기: `3.14`, `1.5e2`, `2e-3` (지수 뒤에 숫자가 없으면 에러로 안내)
- 변수 대입: `x = 100`
- 함수: `sin`, `cos`, `tan` (라디안), `factorial(n)` (n ≤ 1000)
- `#` 이후 줄 끝까지 주석

실행 결과 모달에서 다음 옵션을 선택할 수 있습니다:

- **📥 메모에 삽입** — 코드 다음 줄에 `# 결과` 주석으로 결과를 끼워 넣음 (재실행 시 주석으로 자동 무시)
- **💾 메모리에 저장** — 이번 실행의 변수를 IndexedDB에 영속 저장. 다음 실행에서 자동으로 읽혀 사용 가능 (페이지 새로고침/재시작 후에도 유지)
- **🗑️ 메모리 초기화** — 저장된 변수 모두 삭제 (메모리에 변수가 있을 때만 표시)

예시:

```
x = 100
y = factorial(20)        # 2432902008176640000
(x + y) * 2
7 / 2                    # 3.5
7 // 2                   # 3 (몫)
sin(0) + cos(0)          # 1
```

│   ├── markdown.js       # 마크다운 파서/렌더러

│   └── data-sources/
│       ├── index.js      # 데이터 소스 팩토리
│       ├── indexeddb.js  # 기본 영속 저장소
│       ├── memory.js     # 폴백 인메모리 저장소
│       └── rest.js       # 선택적 REST 저장소

├── bundle.py             # 단일 파일 번들러

└── history.md            # 작업 이력

## 빌드

`build.sh` (Linux/macOS) 또는 `build.bat` (Windows)을 실행하면 `release/` 폴더에 JS/CSS가 모두 인라인된 단일 파일 `release/index.html`이 생성됩니다. 더블 클릭으로 브라우저에서 바로 열 수 있고 (서버 불필요), 원한다면 `cd release && python -m http.server 8001`로 띄울 수도 있습니다.

단일 파일 번들은 `bundle.py` (Python 표준 라이브러리만 사용)가 ES 모듈을 위상 정렬 후 import/export 키워드를 제거하고 인라인합니다.
